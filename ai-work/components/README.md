# Component work records

Each full component feature keeps a restart-safe record at
`ai-work/components/<slug>/` with `brief.md`, `progress.md`, and `validation.md`.
The repository-local
[component lead skill](../../.agents/skills/cocokits-component-lead/SKILL.md)
defines how the lead creates, reconciles, and validates these records. They are
project history suitable for Git; do not use temporary files as their substitute.
